# archive/

Retired files, kept for reference. **Nothing here is needed to run anything.**

- **`simple_dta_scratch/`** — superseded experiment specs and one-off scripts from our
  `simple_dta/` work: old `jobs_*.txt` batch files, the `chain_*.sh` / `run_compare*.sh` /
  `status.sh` helpers we no longer use, and `RESULTS_SUMMARY.md` (the old Markdown results
  table, replaced by `simple_dta/RESULTS_SUMMARY.txt`). Useful as examples of how past
  experiments were specified. The current, live experiment record is
  `simple_dta/EXPERIMENTS.md`.

- **`deepdtagen_repro_notes/`** — early Chinese-language notes (复现/计划/运行/问题.md) on
  reproducing the upstream DeepDTAGen pipeline. Predate our `simple_dta/` work.
